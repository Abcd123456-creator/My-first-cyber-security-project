# Python Password Security Guard

This is my very first cybersecurity project! I built a local security tool using Python that analyzes user input to enforce strong password guidelines.

## 🛠 What This Tool Does
- **Length Check:** Ensures the password is at least 8 characters long to prevent easy guessing.
- **Complexity Check:** Scans the password character by character to verify it contains at least one number.
- **Instant Feedback:** Gives the user clear, color-coded security alerts based on their choices.

## 🚀 How to Run It
1. Download the `security_guard.py` file.
2. Open it in Python's IDLE editor.
3. Press **F5** on your keyboard to run the security guard.
